# Your own templates

Templates here are yours: git ignores this folder (except this file), and the editor lists them
with "(local)". Put the `.json` and `.md` that "Save as template…" downloads here, then run
`python3 host/templates_index.py`. To share one, move it to `editor/templates/` instead and open a
pull request (see [../README.md](../README.md)).
